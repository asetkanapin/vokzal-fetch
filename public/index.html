    Практикум урока: Fetch API

    Задания из плана урока. Запросы идут к JSONPlaceholder и Open-Meteo, результат выводится в один контейнер #output.

    1. Один пост

      GET /posts/1

      Заголовок и текст первого поста, через .then().

    2. Пользователи

      GET /users

      Карточки: имя, email, город, компания. Через async/await.

    3. Посты пользователя

      GET /posts?userId=…

      Параметр запроса в адресе.

      от 1 до 10

    4. Ошибка

      GET /posts/99999

      Несуществующий адрес: проверка response.ok.

    5. Погода в Астане

      api.open-meteo.com

      Температура и скорость ветра. Задание со звёздочкой.

    Результат

    Нажмите любую кнопку слева. Здесь появится ответ сервера.

    Значки пассажира

    Каждый значок — одно состояние из задания. Соберёте все обычные — значит, проверили всё, что нужно для отчёта.
